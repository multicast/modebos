# cloud

Cloud guest tooling: installs `cloud-init` and the cloud/guest utilities (`cloud-guest-utils`, `cloud-image-utils`, `cloud-utils`) plus `netplan.io`, with a netplan-based overlay. Depends on [server](../server/README.md).
