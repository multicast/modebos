# gactions

Toolchain for GitHub Actions runners: `ansible`/`ansible-lint`, `black`, `git`, `nmap`, `python3`, `qemu-utils`, `yamllint`, and related packages. Pulls in [systemd](../systemd/README.md), [cloud](../cloud/README.md), and [kvm](../kvm/README.md).
